# Project Rules & Conventions

## Landing Page Integrity
- **Preserve Visual Identity**: Do NOT change the color composition, typography, or general aesthetic of the landing page.
- **Maintain Content**: Do NOT modify existing text, links, or section details unless explicitly requested.
- **Surgical Edits Only**: When adding or removing features (like a mascot or animation), perform only the necessary changes to implement that specific request. Do not redesign, restyle, or "improve" existing elements.
